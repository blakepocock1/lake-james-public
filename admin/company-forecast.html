Forecast Rules

Base = booked backlog + probability-weighted pipeline + eligible active recurring revenue. Conservative discounts weighted pipeline further. Upside uses 90% of open pipeline. Recurring revenue is counted only for organizations with an active program and an active subscription; onboarding, pilot and demo records are not treated as paid recurring revenue.
